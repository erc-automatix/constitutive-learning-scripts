## Constitutive Learning: supplementary notebooks

[DOI](https://doi.org/10.5281/zenodo.24312131)

This repository contains the numerical examples of the paper

> J. Bleyer and J. S. Hale, *Constitutive Learning: a unification of constitutive models with machine learning for automated material modeling*, 2026, preprint, [⟨hal-05869018⟩](https://hal.science/hal-05869018)

In this framework, classical constitutive models and machine learning models are treated as parameterized, differentiable operators. Each example builds a hybrid constitutive model by substituting, augmenting, composing or parameterizing modules of a metamodel. The models are implemented with [`jaxmat`](https://github.com/erc-automatix/jaxmat), a constitutive modeling
library built on JAX, and calibrated by gradient-based optimization, with gradients obtained by automatic differentiation through the constitutive updates.

## Contents

| Notebook                                | Section of the paper                                                    | Hybridization                                                                                                                    | Data                                           |
| --------------------------------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| `hardening_slot`                        | Elastoplasticity with substitution of the isotropic hardening law       | Substitution of the hardening law: Voce law, sum of exponentials, ICNN, MLP                                                      | X100 steel hardening curve, with added noise   |
| `augmented_hardening`                   | Augmented hybridization on cyclic plasticity tests                      | Neural correction of the isotropic hardening of the Voce-Chaboche model, end-to-end calibration through the implicit update      | Cyclic tests on a structural steel (RESSPyLab) |
| `finite_strain_calibration`             | Finite strain by composition: calibration of a wrapped hybrid model     | Small-strain plasticity with an ICNN hardening law, wrapped in the logarithmic-strain framework; objectivity and Taylor tests    | Tension test on a structural steel (RESSPyLab) |
| `neural_gsm`                            | Physics-augmented generalized standard material for viscoelasticity     | Free energy and dissipation potential of a generalized standard material implemented by input-convex networks                    | Synthetic, generated in the notebook           |
| `temperature_dependent_viscoelasticity` | Parameter-level hybridization: a hypernetwork for thermoviscoelasticity | Prony series of a generalized Maxwell model generated by networks of the temperature, compared with Arrhenius and WLF shift laws | Synthetic, generated in the notebook           |

Each notebook is stored in two paired formats: a Jupyter notebook (`.ipynb`), which includes the
outputs, and a Python script in the `py:percent` format (`.py`), which is convenient for version
control and review. The two files are kept synchronized with [Jupytext](https://jupytext.readthedocs.io).

## Installation

The examples require Python 3.11 or later, `jaxmat` version 0.1 and its dependencies (JAX, Equinox, Optimistix, paramax), together with NumPy, SciPy, pandas and Matplotlib:

```bash
python -m venv .venv
source .venv/bin/activate
pip install jaxmat==0.1
pip install numpy scipy pandas matplotlib jupyterlab jupytext
```

`jaxmat` enables double precision in JAX, which all the examples use. The examples run on a CPU; a GPU is not required.

## Running the examples

Open a notebook in Jupyter:

```bash
cd hardening_slot
jupyter lab hardening_slot.ipynb
```

or execute it from the command line, which regenerates the outputs of the `.ipynb` file:

```bash
cd hardening_slot
jupytext --to ipynb --execute hardening_slot.py
```

The Python scripts can also be run directly, for instance with a non-interactive matplotlib backend:

```bash
cd hardening_slot
MPLBACKEND=Agg python hardening_slot.py
```

## Data

- `X100.csv`: yield stress of an X100 pipeline steel as a function of the cumulated plastic strain, from the dataset of the MEALOR summer school on ductile fracture: [GitHub - MEALORII/TP_MEALOR](https://github.com/MEALORII/TP_MEALOR/tree/main) (GPL 3.0 license)
- `example_1.csv`, `example_2.csv`, `tension_test.csv`: cyclic and monotonic uniaxial tests on a structural steel, given as true stress versus true strain, distributed as examples with [RESSPyLab](https://pypi.org/project/RESSPyLab/) (A. de Castro e Sousa, A. R. Hartloper and
  D. G. Lignos), under the MIT license; the license notice is given in `LICENSE-RESSPyLab`. A database of such coupon tests on structural steels is available on Zenodo (Hartloper et al., 2022, [doi:10.5281/zenodo.6965147](https://doi.org/10.5281/zenodo.6965147)).
- The data of `neural_gsm` and `temperature_dependent_viscoelasticity` are generated in the notebooks by reference constitutive models. The reference model of `neural_gsm`, its parameters and the protocol for the strain paths are those of Rosenkranz et al. (2024).
